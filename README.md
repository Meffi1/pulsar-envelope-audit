\# Аудит криптографических конвертов Pulsar



Этот репозиторий содержит изолированные тесты для проверки безопасности механизма шифрования конвертов в протоколе Pulsar (DKG).



\## Что проверяется



1\. \*\*Кросс-комитетный replay (`TestSealOpenEnvelope\_CrossCommitteeReplay`)\*\*

&#x20;  - Проверяет, что конверт, созданный для одного `committeeRoot`, не может быть открыт в контексте другого комитета.

&#x20;  - Это подтверждает корректность исправления аудита CR-6 (привязка обязательств к committee root).



2\. \*\*Переиспользование `encapSeed` (`TestSealEnvelope\_EncapSeedReuse`)\*\*

&#x20;  - Проверяет, что даже при использовании одинакового `encapSeed` для разных долей секрета, зашифрованные данные (`Sealed`) получаются разными.

&#x20;  - Это исключает возможность компрометации через детерминированное шифрование.
